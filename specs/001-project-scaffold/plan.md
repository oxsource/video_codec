# Implementation Plan: Project Scaffolding (video_codec)

**Branch**: `001-project-scaffold` | **Date**: 2026-08-11 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-project-scaffold/spec.md`, design
from `codec/doc/project_bootstrap.md`, and structure modeled on
`native_ui/specs/001-project-scaffold/plan.md`.

## Summary

Establish the Bazel workspace (rooted at `codec/`), platform definitions,
dependency management (FFmpeg via `http_archive`, Android NDK via toolchain), and
the module skeleton (`core`, `api`, `backend/{android,ffmpeg}`, `utils`, `public`)
for the cross-platform audio/video encoding framework. This phase carries the
highest technical risk — FFmpeg's `libavcodec` Bazel integration and Android NDK
wiring for MediaCodec. Two spikes prove the integrations: `ffmpeg_spike` encodes a
synthetic frame to a valid `.h264` on the dev host; `mediacodec_spike` validates
`AMediaCodec` configuration and builds only under the Android toolchain so it never
breaks the host build.

## Technical Context

**Language/Version**: C++17 (`-fvisibility=hidden`)

**Build System**: Bazel 6.5.0

**Primary Dependencies**: FFmpeg 6.1 (`libavcodec`/`libavutil`, encoding), Android
NDK (`AMediaCodec`, Android encoding), googletest (testing), bazel_skylib (build helpers)

**Storage**: N/A

**Testing**: googletest

**Target Platform**: Android ARM64 (primary MediaCodec backend), Linux x86_64
(primary FFmpeg backend / CI), macOS ARM64 (development host, reserved for
VideoToolbox Phase 2+)

**Project Type**: C++ shared library

**Performance Goals**: N/A (scaffolding phase — no runtime performance targets)

**Constraints**: FFmpeg must be isolated behind `backend/ffmpeg`; no other module
may depend on `@ffmpeg` directly. NDK media headers isolated behind
`backend/android`. Host (Linux/macOS) build must succeed without Android NDK.

**Scale/Scope**: Single library with 6 internal modules (core, api, utils,
backend/android, backend/ffmpeg, public) plus 2 spike binaries and test targets.
(`backend/darwin` reserved, not created in P1.)

### Source Code (workspace root: `codec/`)

```text
codec/                              # Bazel workspace root
├── BUILD.bazel                     # Root alias: //:video_codec → //src/framework/public:video_codec
├── WORKSPACE                       # workspace(name = "video_codec")
├── video_codec_deps.bzl            # External dependency bootstrap (video_codec_setup)
├── .bazelversion                   # 6.5.0
├── .bazelrc                        # C++17, platform aliases
├── .bazelignore
├── platforms/
│   ├── BUILD                       # config_setting + platform for android_arm64, linux_x86_64, darwin_arm64
│   └── platforms.bzl               # config_setting_and_platform macro
├── third_party/
│   ├── ffmpeg/
│   │   └── BUILD.bazel             # FFmpeg cc_library wrapper
│   └── android_ndk/
│       └── BUILD.bazel             # NDK media header wrapper (host-referenced)
├── src/
│   └── framework/
│       ├── core/                  # empty cc_library stub
│       │   └── BUILD.bazel
│       ├── api/                   # empty cc_library stub
│       │   └── BUILD.bazel
│       ├── utils/                 # empty cc_library stub
│       │   └── BUILD.bazel
│       ├── backend/
│       │   ├── android/           # empty cc_library stub (NDK dep)
│       │   │   └── BUILD.bazel
│       │   └── ffmpeg/            # empty cc_library stub (@ffmpeg dep)
│       │       └── BUILD.bazel
│       └── public/                # umbrella target, select()s backend
│           ├── BUILD.bazel
│           └── include/video_codec/
│               └── video_codec_export.h   # VIDEO_CODEC_API macro
├── src/spike/
│   ├── BUILD.bazel                 # ffmpeg_spike + mediacodec_spike targets
│   ├── ffmpeg_spike.cc             # synthetic NV12 frame → .h264 (runs on host)
│   └── mediacodec_spike.cc         # AMediaCodec config (Android-only build)
└── tests/
    └── BUILD.bazel                 # empty test target (infra present)
```

**Structure Decision**: Flat single-workspace layout mirroring `native_ui`
conventions. Each framework module is a separate Bazel package. Third-party deps
use `third_party/` wrappers. The spikes live in their own `src/spike/` package to
isolate risk. Workspace root is `codec/` (per `project_bootstrap.md`), keeping the
encoding library self-contained while `specs/` stays at the git repo root for
spec-kit tooling.
